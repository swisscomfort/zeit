# Zeit

Reproduzierbarer Prüfstand zur Hypothese einer relativen Zeitdrift zwischen unabhängigen physikalischen Zeitstandards.

## Arbeitsregel

Der kanonische Forschungsstand liegt lokal unter `~/zeitdrift-ipta` und wird nur evidenzbasiert fortgeschrieben. Ein zusätzlicher Zeitdrift-Parameter `a_t` wird erst eingeführt, nachdem eine unveränderte reale Standardmodell-Residualbaseline reproduziert wurde.

## Aktueller Stand

- Phasen 1–7: unabhängige Zeit-/Driftindikatoren und methodische Grenzen untersucht.
- Phase 8: offener PEP-Fit-Engine-Build reproduziert und validiert.
- Phase 9A: interne PEP-Radiometrie-Regression reproduzierbar; nur Testdaten.
- Phase 9B: reale externe EDC/DGFI-TUM Apollo-15-LLR-Normalpunkte vom 10.12.2006 erfolgreich in PEP-OBSLIB ingestiert.
- Phase 9C: NASA/ILRS-MLRS-Lunar-Referenzkette wird unverändert reproduziert, bevor die realen 2006-LLR-Daten als O−C-Standardmodellbaseline verwendet werden.

## Reproduzierbarkeit

Große Fremddaten, heruntergeladene Vendor-Archive, Build-Verzeichnisse und Laufzeitartefakte sollen nicht ungeprüft in Git versioniert werden. Stattdessen werden Provenienz, URL, Version/Commit und SHA-256 dokumentiert.
